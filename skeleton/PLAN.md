### 인증·계정 운영

- [ ] **비밀번호 변경 화면**: 사용자가 스스로 비밀번호를 바꿀 화면이 없다(운영자는 `python -m app.cli set-password` 를 쓴다).
      `validate_new_password` 를 재사용하고, 변경 성공 시 현재 세션 외 `auth_sessions` 를 모두 폐기하는 것까지 한 단위로 만든다.
- [ ] **사용자 생성·가입 경로**: 관리자 화면은 목록·역할 변경·비활성화·세션 폐기·잠금 해제만 한다.
      사용자 생성(초대·회원가입) 화면은 서비스 특성에 맞춰 추가한다(서비스 함수 `create_user` 는 있다).
- [ ] **본인 세션 관리**: 관리자용 세션 목록·폐기는 있지만 사용자 본인의 「내 기기 목록·전 기기 로그아웃」은 없다.
- [ ] **세션·스로틀 테이블 청소**: `auth_sessions` 는 로그인마다, `login_throttles` 는 실패한 username 마다 행이 쌓이는데
      자동 삭제 경로가 없다. 만료·폐기 세션과 오래된 스로틀 행을 지우는 주기 작업을 추가한다.
- [ ] **계정 잠금 DoS 완화 검토**: 로그인 스로틀이 username 기준이라 제3자가 남의 아이디로 연속 실패시키면 그 계정이
      잠긴다(기본 5회·15분). 공개 서비스라면 IP 결합·캡차 등 완화를 결정한다.
